# O'G IPTV Demo
Xtream-compatible experimental API for public IPTV-org playlists. Not a commercial IPTV service. Adult category is empty. Some sources may fail or be geo-blocked.

Render: Python, build `pip install -r requirements.txt`, start `python server.py`, environment `IPTV_USER` and `IPTV_PASSWORD`.

Xtream login: `https://<your-render-host>`, username/password from environment variables.
